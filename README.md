# Four Pass Loop App

Complete static iPhone web app for the August 9–11, 2026 clockwise Four Pass Loop trip.

## Deploy

Copy every file and folder in this package into the root of the GitHub repository. The root must contain `index.html`, `styles.css`, `app.js`, and the `images` folder. Commit and push; Vercel will redeploy automatically.

## Install on iPhone

Open the Vercel address in Safari, tap Share, choose **Add to Home Screen**, and enable **Open as Web App** when offered.
